# study-log

我的测试学习日志，方向是测试开发。记录每天学了什么、卡在哪、明天接着干什么。

## 目录约定

- `logs/` 下一篇一天，文件名 `YYYY-MM-DD.md`
- 同一天要分开写就加后缀，例如 `2026-10-21-http.md`
- 练习代码放 `code/`，按主题建子目录

## 写日志的规矩

固定三段，别写成长篇心得，能让三个月后的自己看懂就行：

```markdown
# 2026-10-21

## 今天做了什么
## 卡住的地方
## 明天
```

## 提交流程

```bash
git add .
git commit -m "2026-10-21: 一句话说明今天学了什么"
git push
```
