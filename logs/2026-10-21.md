## 卡住的地方

浏览器能打开 GitHub，命令行 `git` 却报 `Recv failure: Connection was reset`。

原因是 **git 不走 Windows 系统代理**。浏览器用的是系统代理 `127.0.0.1:4088`，但 git 有自己的配置项，默认不读系统代理，所以同一个网络下两边表现不一致。

解法（把 git 也指向同一个代理）：

```bash
git config --global http.proxy  http://127.0.0.1:4088
git config --global https.proxy http://127.0.0.1:4088
```

代理软件关掉以后 git 反而会连不上，撤销：

```bash
git config --global --unset http.proxy
git config --global --unset https.proxy
```

验证是否通了：

```bash
git ls-remote https://github.com/git/git.git HEAD
```

能返回一个 commit hash 就说明通了。
